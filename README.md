Računalne komponente
Ovo je moj školski projekt u kojem sam napravio web stranicu o računalnim komponentama.

Stranice
- "index.html" – početna stranica na kojoj su predstavljene osnovne računalne komponente.
- "usluge.html" – stranica na kojoj su prikazane komponente i neke usluge.
- "kontakt.html" – stranica s kontaktnim podacima i obrascem za poruku.

Korištene tehnologije
Za izradu stranice koristio sam HTML i Tailwind CSS. Tailwind CSS sam uključio preko CDN-a, tako da nisam morao napraviti posebnu CSS datoteku.

Stranica je prilagođena računalima i mobitelima.
